# Smokey Doughs Bolton

React website adapted for GitHub Pages with the full menu, pizza customisations, meal deals, saved basket and checkout preview.

## Status
Source code published. Deployment is pending the original image and video asset transfer. `public/assets/` must be populated before deploying.

Payments and order submission remain disabled. Customer contact details stay in page memory; basket choices are saved locally.

## Development
Node 22+: `npm install`, then `npm run dev`. Build with `npm run build`. The build emits separate page directories for GitHub Pages under `/smokey-doughs-bolton/`.
